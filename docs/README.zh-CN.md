## 作为 Product 规范使用

客户需求和资源保留在对应 Product 仓库内。用已确认需求替换合成定义，不得把 Demo 协议值直接当作车辆默认值。保留文档分区、源码清单、专用构建目录、双语检查及渲染证据流程。

Framework 集成说明归 Framework；Product 使用方法、验收记录和设计对照归本仓库。返回[仓库入口](../README.zh-CN.md)。
