## Use this as a Product standard

Keep customer requirements and assets inside their Product repository. Replace synthetic definitions with confirmed requirements; never copy Demo protocol values as vehicle defaults. Retain the documentation sections, source manifest, dedicated build directory, bilingual checks and renderer evidence workflow.

Framework integration instructions belong to Framework. Product-specific usage, acceptance records and design comparisons belong here. Return to the [repository entry](../README.md).
